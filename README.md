# Skinstric AI

A responsive skincare-analysis experience created as a front-end internship project. The application guides users through identity intake, image capture or upload, API-powered analysis, and demographic result views.

## Features

- Multi-step React Router flow
- Name and location intake form
- Camera capture and image upload options
- Client-side image resizing and conversion
- API-powered image analysis
- Demographic result categories and confidence scores
- Loading, permission, retry, and error states
- Local storage for captured images and analysis results
- Responsive desktop and mobile layouts

## Built With

- React
- Vite
- JavaScript
- React Router
- REST APIs

## Requirements

- Node.js 22 or newer
- npm

## Installation

```bash
git clone https://github.com/Miingo954/skin-stric-ai.git
cd skin-stric-ai
npm install
```

## Run Locally

```bash
npm run dev
```

Open the local URL shown by Vite in your terminal.

## Available Scripts

```bash
npm run dev
npm run build

```
